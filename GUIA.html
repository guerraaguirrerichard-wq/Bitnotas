Login + Registro desde cero

Aprende a construir autenticación completa paso a paso — con localStorage

¿Qué vamos a construir?

Antes de escribir código, entendamos qué es un inicio de sesión, un registro, y cómo funcionan juntos.

🔐

Autenticación

Verificar que el usuario es quien dice ser. Compara lo que escribes con lo guardado.

📝

Registro

Crear una cuenta nueva. Recoge los datos del usuario y los guarda para uso futuro.

🗄️

localStorage

Almacenamiento del navegador. Guarda datos como texto JSON sin necesitar un servidor.

🍪

Sesión / Token

Tras iniciar sesión, el servidor entrega un "pase" que recuerda que el usuario está activo.

📋

Flujo completo: Registro → Login

Ahora el flujo tiene dos caminos. Primero el usuario se registra, luego puede iniciar sesión:

¿Qué hace cada atributo?

  • ✔
    type="email" — El navegador valida automáticamente el formato (con @)
  • ✔
    type="password" — Oculta los caracteres con puntos o asteriscos
  • ✔
    required — El formulario no se envía si el campo está vacío
  • ✔
    placeholder — Texto de ejemplo que desaparece al escribir
  • ✔
    for / id — Conecta el label con el input; hacer clic en el texto activa el campo
  • ✔
    style="display:none" — Oculta el panel de registro al cargar la página

    if (input.type === 'password') {
      input.type = 'text';
      btn.textContent = '🙈';
    } else {
      input.type = 'password';
      btn.textContent = '👁️';

}

Alternar entre Login y Registro

script.js — mostrarTab
function mostrarTab(tab) {
  const panelLogin    = document.getElementById('panelLogin');
  const panelRegistro = document.getElementById('panelRegistro');
  const tabLogin      = document.getElementById('tabLogin');
  const tabRegister   = document.getElementById('tabRegister');

  if (tab === 'login') {
    panelLogin.style.display    = 'block';
    panelRegistro.style.display = 'none';
    tabLogin.classList.add('active');
    tabRegister.classList.remove('active');
  } else {
    panelLogin.style.display    = 'none';
    panelRegistro.style.display = 'block';
    tabLogin.classList.remove('active');
    tabRegister.classList.add('active');
  }
}
4

Lógica del formulario de Login

script.js — submit login
form.addEventListener('submit', function(e) {
  e.preventDefault();

  // 1. Limpiar errores anteriores
  emailError.textContent = '';
  passError.textContent  = '';
  loginAlert.className   = 'alert';

  // 2. Obtener los valores
  const email    = emailInput.value.trim().toLowerCase();
  const password = passInput.value;

  // 3. Validar campos vacíos
  let hayError = false;
  if (!email) { emailError.textContent = '⚠️ El correo es obligatorio'; hayError = true; }
  if (!password) { passError.textContent = '⚠️ La contraseña es obligatoria'; hayError = true; }
  if (hayError) return;

  // 4. Buscar en todos los usuarios (fijos + localStorage)
  const usuario = obtenerUsuarios().find(u =>
    u.email === email && u.password === password
  );

  // 5. Mostrar resultado
  if (usuario) {
    loginAlert.className   = 'alert success';
    loginAlert.textContent = `✅ ¡Bienvenido, ${usuario.nombre}! Redirigiendo...`;
    setTimeout(() => window.location.href = 'dashboard.html', 1500);
  } else {
    loginAlert.className   = 'alert error';
    loginAlert.textContent = '❌ Correo o contraseña incorrectos';
  }
});
🧠 e.preventDefault() es fundamental: evita que el formulario recargue la página al enviarse, lo que borraría el mensaje de error antes de que el usuario lo vea.

📝 Registro con localStorage

Cómo guardar usuarios nuevos en el navegador y validar el formulario de registro.

✨ Nueva sección: Aquí aprenderás a usar localStorage para persistir usuarios registrados, combinándolos con los usuarios fijos del array original.
1

¿Qué es localStorage?

Es un almacenamiento clave-valor del navegador que sobrevive cuando cierras y vuelves a abrir la página:

localStorage — conceptos básicos
// Guardar un valor (solo admite strings)
localStorage.setItem('clave', 'valor');

// Guardar un objeto → convertir a JSON primero
const datos = { nombre: 'Ana', email: 'ana@correo.com' };
localStorage.setItem('usuario', JSON.stringify(datos));

// Leer un valor
const texto = localStorage.getItem('clave'); // → 'valor'

// Leer un objeto → convertir de JSON
const obj = JSON.parse(localStorage.getItem('usuario'));

// Eliminar un elemento
localStorage.removeItem('clave');

// Limpiar todo
localStorage.clear();
2

Funciones para manejar usuarios

Tres funciones que abstraen toda la lógica de leer, guardar y verificar usuarios:

script.js — funciones localStorage
// Usuarios fijos — siempre disponibles, no se guardan en localStorage
const USUARIOS_DEFAULT = [
  { nombre: 'Admin',      email: 'elprofe@gmail.com',      password: 'Admin123' },
  { nombre: 'Estudiante', email: 'estudiante@correo.com', password: 'Pass456'  }
];

/**
 * Devuelve TODOS los usuarios: fijos + los guardados en localStorage
 */
function obtenerUsuarios() {
  const guardados = JSON.parse(localStorage.getItem('usuarios') || '[]');
  return [...USUARIOS_DEFAULT, ...guardados]; // spread operator fusiona ambos arrays
}

/**
 * Guarda un nuevo usuario al final de la lista en localStorage
 */
function guardarUsuario(nuevoUsuario) {
  const guardados = JSON.parse(localStorage.getItem('usuarios') || '[]');
  guardados.push(nuevoUsuario);
  localStorage.setItem('usuarios', JSON.stringify(guardados));
}

/**
 * Verifica si un correo ya está registrado (en cualquiera de las listas)
 */
function emailExiste(email) {
  return obtenerUsuarios().some(u => u.email === email.toLowerCase());
}
3

Validaciones del formulario de registro

Antes de guardar, verificamos que todos los datos sean correctos. El orden importa — paramos en el primer error:

script.js — validaciones de registro
registerForm.addEventListener('submit', function(e) {
  e.preventDefault();

  const nombre    = regNombre.value.trim();
  const email     = regEmail.value.trim().toLowerCase();
  const password  = regPassword.value;
  const passwordC = regPasswordConf.value;
  let hayError = false;

  // Validar nombre
  if (!nombre || nombre.length < 2) {
    nombreError.textContent = '⚠️ Nombre demasiado corto';
    hayError = true;
  }

  // Validar correo no duplicado
  if (!validarEmail(email)) {
    regEmailError.textContent = '⚠️ Formato de correo no válido';
    hayError = true;
  } else if (emailExiste(email)) {
    regEmailError.textContent = '⚠️ Este correo ya está registrado';
    hayError = true;
  }

  // Validar seguridad de contraseña
  const erroresPass = validarPassword(password);
  if (erroresPass.length > 0) {
    regPassError.textContent = '⚠️ ' + erroresPass.join(' · ');
    hayError = true;
  }

  // Validar que ambas contraseñas coincidan
  if (password !== passwordC) {
    regPassConfError.textContent = '⚠️ Las contraseñas no coinciden';
    hayError = true;
  }

  if (hayError) return; // detener si hay cualquier error

  // ✅ Todo válido — guardar y mostrar éxito
  guardarUsuario({ nombre, email, password });
  registerAlert.className   = 'alert success';
  registerAlert.textContent = `✅ ¡Cuenta creada! Bienvenido, ${nombre}.`;

  registerForm.reset();
  setTimeout(() => mostrarTab('login'), 2000); // redirigir al login
});

Paso 4 — Validaciones avanzadas

Mejora la experiencia y seguridad con validaciones más completas.

1

Validar formato de correo

Un correo válido debe tener el formato usuario@dominio.com. Usamos una expresión regular (Regex):

Validación de email
function validarEmail(email) {
  // Expresión regular para formato de correo
  const regex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  return regex.test(email);
}

// Uso:
validarEmail('usuario@correo.com'); // → true  ✅
validarEmail('testmail.com');        // → false ❌ (sin @)
validarEmail('test@mailcom');        // → false ❌ (sin .)
2

Validar seguridad de contraseña

Validación de contraseña
function validarPassword(pass) {
  const errores = [];

  if (pass.length < 8)
    errores.push('Mínimo 8 caracteres');

  if (!/[A-Z]/.test(pass))
    errores.push('Al menos una mayúscula');

  if (!/[0-9]/.test(pass))
    errores.push('Al menos un número');

  return errores; // Array vacío = contraseña válida
}

validarPassword('hola');     // → ['Mínimo 8 caracteres', 'Al menos una mayúscula', ...]
validarPassword('Segura123'); // → [] ✅ válida
3

Indicador de fortaleza de contraseña

Una barra visual que le dice al usuario qué tan segura es su contraseña mientras escribe:

Medidor de seguridad
/* Ya está en el HTML dentro del form-group de regPassword: */
<div id="fortaleza"><div id="barraFuerza"></div></div>
<span id="textoFuerza"></span>

/* En el JS: */
const barraFuerza = document.getElementById('barraFuerza');
const textoFuerza = document.getElementById('textoFuerza');

regPassword.addEventListener('input', () => {
  const errores = validarPassword(regPassword.value);
  const puntaje = 3 - errores.length; // 0=nada, 1=débil, 2=regular, 3=fuerte

  const config = [
    { pct: '0%',   color: '#e0e0e0', label: ''           },
    { pct: '33%',  color: '#e53935', label: '😬 Débil'   },
    { pct: '66%',  color: '#ffb300', label: '😐 Regular' },
    { pct: '100%', color: '#43a047', label: '💪 Fuerte'  },
  ][puntaje];

  barraFuerza.style.width      = config.pct;
  barraFuerza.style.background = config.color;
  textoFuerza.textContent      = config.label;
});
🚨 Seguridad importante: La validación en JavaScript solo mejora la experiencia de usuario. Nunca es suficiente por sí sola — el servidor también debe validar todos los datos recibidos.
